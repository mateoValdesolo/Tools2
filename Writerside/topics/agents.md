# Agentes IA

## Superpowers
Superpowers es una metodología completa de desarrollo de software para agentes de código, construida sobre un conjunto de skills componibles. Guía a los agentes de IA (como Claude Code, Cursor o GitHub Copilot) a través de las fases de diseño, planificación, desarrollo dirigido por pruebas y revisión de código.
[Link](https://github.com/obra/superpowers)

## ECC
ECC es un sistema de optimización del rendimiento para agentes de IA de código como Claude Code o Cursor. Aporta agentes especializados, skills, hooks y reglas con flujos de trabajo listos para producción, cubriendo la implementación de funcionalidades, la revisión de código y la corrección de errores en más de 12 ecosistemas de lenguajes.
[Link](https://github.com/affaan-m/ecc)

## UI UX Pro Max
UI UX Pro Max es una skill que aporta "inteligencia de diseño" a Claude Code, integrando capacidades de diseño de interfaces en el flujo de trabajo del agente para generar interfaces más cuidadas y profesionales.
[Link](https://ui-ux-pro-max-skill.nextlevelbuilder.io/)

## Impeccable
![Impeccable](impeccable.png){width="50" style="inline"}
Impeccable es el vocabulario de diseño que les falta a los agentes de IA: un conjunto de 23 comandos sobre tipografía, color, layout y movimiento que da a los agentes de código un lenguaje compartido para colaborar en diseño frontend, eliminando los defectos estéticos habituales del código generado por IA y respetando los sistemas de diseño existentes.
[Link](https://impeccable.style/)

## GSD Core
GSD Core es un framework ligero de meta-prompting, ingeniería de contexto y desarrollo guiado por especificaciones que ayuda a los agentes de IA de código (Claude Code, Copilot, Cursor) a trabajar de forma más eficaz gestionando la ventana de contexto mediante un ciclo de cinco fases: Discutir, Planificar, Ejecutar, Verificar y Entregar. Combate el "context rot" ejecutando la investigación y planificación pesada en subagentes nuevos mientras mantiene el estado del proyecto organizado.
[Link](https://github.com/open-gsd/gsd-core)

## Graphify
![Graphify](graphify.png){width="50" style="inline"}
Graphify es una skill para asistentes de IA de código que construye grafos de conocimiento consultables y multimodales a partir de código, documentación, papers, imágenes y diagramas. Actúa como una capa de memoria del repositorio, permitiendo que el agente razone sobre la estructura y las relaciones del proyecto usando una fracción de los tokens.
[Link](https://graphify.net/)

## Engram
Engram es un sistema de memoria persistente para agentes de IA de código que almacena la información en una base de datos SQLite local. Se distribuye como un único binario en Go con varias interfaces (CLI, API HTTP, servidor MCP y TUI) y funciona con agentes como Claude Code, Gemini CLI o Cursor para conservar el contexto entre sesiones.
[Link](https://github.com/Gentleman-Programming/engram)

## AGENTS.md
![AGENTS.md](agentsmd.png){width="50" style="inline"}
AGENTS.md es un formato abierto y estándar que define un archivo dedicado para dar a los agentes de IA de código el contexto técnico y las instrucciones que necesitan para trabajar en un proyecto. Funciona como un "README para agentes": un lugar predecible que complementa la documentación pensada para personas.
[Link](https://agents.md/)

## OpenSpec
![OpenSpec](openspec.svg){width="50" style="inline"}
OpenSpec es un framework ligero de desarrollo guiado por especificaciones que actúa como capa de planificación para los agentes de IA de código. Permite crear y mantener especificaciones junto al código, generar propuestas de cambio con sus tareas de implementación y colaborar en la planificación de funcionalidades a lo largo de varias sesiones, manteniendo los requisitos como documentación viva dentro del repositorio.
[Link](https://openspec.dev/)
